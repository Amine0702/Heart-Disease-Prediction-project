# Heart Disease Prediction with Decision Tree

## Project Description
This project uses a **Decision Tree Classifier** to predict heart disease based on patient data.
It includes **data exploration**, **feature importance analysis**, **hyperparameter tuning**, and **visualization** of the decision tree.

## Objectives
- Explore and visualize heart disease dataset using **Pandas** and **Seaborn**
- Handle categorical and numerical features
- Train a Decision Tree Classifier
- Evaluate model performance using accuracy score
- Perform **hyperparameter tuning** with GridSearchCV
- Visualize the trained decision tree


## Libraries Used
- Python
- pandas
- seaborn
- matplotlib
- scikit-learn (DecisionTreeClassifier, train_test_split, GridSearchCV)

## Key Features
1. **Data Exploration**
   - Countplots for categorical variables
   - Heatmap of correlation between features
2. **Decision Tree Classifier**
   - Model training and prediction
   - Feature importance evaluation
   - Hyperparameter tuning (max_depth, min_samples_leaf)
3. **Visualization**
   - Decision tree visualization using `plot_tree`
